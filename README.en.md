# Project — Web Demo

A static web demo with login, customers, and addresses pages. HTML, CSS, and JavaScript files implement the interface without an application backend in this repository.

## Stack
- HTML
- CSS
- JavaScript
- Docker for serving static files

## Run
Open `index.html` in a browser or run with Docker:

```bash
docker build -t projeto .
docker run --rm -p 8080:80 projeto
```
